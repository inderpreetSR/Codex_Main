# Learning-first design previews

These local, static concepts explore a guided data-science learning experience.
The ambient design includes light and dark themes, subtle backlit surfaces and
labeled navigation icons. The green design is retained as a comparison.

From this directory, run:

    python -m http.server 9002 --bind 127.0.0.1

Open http://127.0.0.1:9002/ambient.html for the desktop concept or
http://127.0.0.1:9002/ambient-mobile.html for the phone-frame preview. The
original learning concept is at /learning.html and its mobile concept is at
/mobile.html. Stop the server with Ctrl+C. The server is for local review only.

Only the theme switch is functional. Navigation, lesson controls and AI prompts
are illustrative. Example project and learning content are fictional. These
files do not change the application or its authentication and backend.
